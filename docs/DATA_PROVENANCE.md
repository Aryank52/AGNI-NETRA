# AGNI-NETRA — Data Provenance & Scientific Lineage Documentation

## 1. Scientific Data Provenance Principles

AGNI-NETRA strictly preserves the chain of custody for every observational record from initial sensor radiance to final decision support:

1. **Immutable Ingestion Timestamps**: Records exact UTC ingestion time alongside original satellite acquisition time.
2. **Source ID Tracking**: Stores native external identifier (e.g. NASA FIRMS record ID, OSM way ID, CEA plant code).
3. **Processing Lineage Trail**: Maintains an auditable 10/11-stage lineage log for every clustered event.
4. **Separation of Real vs Simulated Data**:
   - `REAL SATELLITE DATA`: Live or historical records originating from NASA FIRMS, Sentinel, Landsat, MOSDAC.
   - `SIMULATED SATELLITE DATA`: Synthetic or replayed records generated by AGNI-SAT digital twin.

## 2. Lineage Stages Specification

```
[STAGE 1]  SATELLITE_SIMULATION  (if simulated: Spacecraft orbit, sensor state, radiance)
[STAGE 2]  RAW_TELEMETRY         (Sensor payload, overpass timestamp, day/night, raw metadata)
[STAGE 3]  DETECTION             (Radiometric extraction, FRP MW, Brightness K)
[STAGE 4]  EVENT_CLUSTER         (Spatiotemporal DBSCAN 1.5km epsilon, bounding box, convex hull)
[STAGE 5]  SPATIAL_ENRICHMENT    (PostGIS spatial indexing, nearest facility distance, state/district)
[STAGE 6]  LULC_CONTEXT          (ISRO Bhuvan 24m LULC classification)
[STAGE 7]  SATELLITE_CONTEXT     (Copernicus Sentinel-2 & Landsat STAC catalog linkage)
[STAGE 8]  FEATURE_VECTOR        (18-dimensional remote sensing tabular features)
[STAGE 9]  MODEL_INFERENCE       (XGBoost primary classifier + Shannon entropy uncertainty)
[STAGE 10] SHAP_EXPLANATION      (SHAP TreeExplainer local Shapley attribution waterfall)
[STAGE 11] DECISION_SUPPORT      (Multi-criteria risk scoring, alerts, HITL verification queue)
```
